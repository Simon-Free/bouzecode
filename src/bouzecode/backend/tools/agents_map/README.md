# tools/agents_map/

## Purpose
Two code-navigation maps an agent reads instead of opening files: a root `AGENTS.md` saying
which folder to go to, and one `SYMBOLS.md` per code folder saying which symbol to open. A
map whose recorded hashes still match the folder is served for free; a stale one is
regenerated by a single LLM call and mechanically validated before it is written.

## Usage
- `tools.py` — the two registered tools `AgentsMap` (no arguments) and `SymbolMap` (`path`, a file path maps its parent folder), plus `repo_root()`. Both are read-only and snippetable
- `serve.py` — the cache protocol: `symbol_map`, `agents_map`, `mark_self_authored` (a folder this agent just edited is served with a stale notice rather than billed for its own churn), `_regenerate` / `_produce_valid` (generate, and on a contract breach retry ONCE with the violations fed back), `_take_lock` / `_release` (`O_EXCL` lock file with a `LOCK_TTL_S` of 120 s), `_atomic_write`, `_stale_notice`, `_client`
- `manifest.py` — freshness machinery: `code_files`, `iter_code_folders`, `is_ignored_dir`, `sha_of`, `line_count`, `folder_manifest`, `tree_sha`, `split_frontmatter` / `render_frontmatter` (deterministic, no timestamp), `staleness` (the reason list; empty means serve as is), `feature_enabled`, `code_exts`
- `prompts.py` — `SYMBOLS_SYSTEM_PROMPT`, `AGENTS_SYSTEM_PROMPT`, `CONTRACT_VERSION`. The contract a generated map must satisfy: required sections, the two tree line shapes (a two-dash connector is a CALL and carries `[file]`, a one-dash connector is a control-flow label), no invented identifier, no sub-folder in a `SYMBOLS.md`
- `inputs.py` — what a regeneration is shown: `build_symbols_message`, `build_agents_message`, `split_changed` (changed files in full, unchanged by name only), `symbol_names`, `legal_identifiers` (own symbols + imports + builtins + parameter names), `code_folder_paths`
- `contract.py` — mechanical validation of the answer: `validate` (a `SYMBOLS.md`) and `validate_root` (the root map, including the ends-mid-row truncation check and the missing-folder check), `call_lines`, `annotation_rate`, `cited_identifiers`, `zoom_ranges`, `wrong_zoom_ranges`, `purpose_cells`, `over_cap_rate`, `PURPOSE_CAP`
- `nesting.py` — `wrong_nesting`: indentation claims "A calls B", so the claim is checked against the AST. `calls_made_by`, `nested_as_arguments` (a call computed inside another's argument list reads as nested and is tolerated), `_aliases`
- `regen.py` — the generation call itself: `model_name`, `call_llm` (streams when the client can and an `on_delta` is given, else blocks), `generate_symbols`, `generate_agents`, `compose`, `symbols_manifest`, `agents_manifest`, `strip_fence`, `AGENTS_MAX_TOKENS`
- `progress.py` — `progress_reporter`: a throttled `report(accumulated_text)` emitting one full text line per interval, so progress survives the carriage-return filtering applied to the streamed log
- `__init__.py` re-exports the public surface (`agents_map`, `symbol_map`, `mark_self_authored`, `staleness`, `feature_enabled`, the two document names)
