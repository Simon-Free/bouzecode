# fr/conv/

## Purpose
French messages for the Conversations page, one file per screen area, mirroring
`en/conv/` key for key. Registered with `window.i18n.register("fr", { ... })`.

## Usage
- `sidebar.js` — the conversation list: state sections, an agent card, its counters and actions
- `panel.js` — the inside of a tab: meta line, message body, tool blocks
- `composer.js` — the send area: the option banners (agent type and launch settings) and the send controls
